A miniature diorama on a round wooden table summing up Tuesday, November 24, 2026's world news in one image — a golden globe at the centre, ringed by six tiny scenes with brass name plates. Entry for the [make.fun bounty "Sum up 24 November's world news in one image"](https://make.fun/bounty/news-image-20261124).

## The six stories

- **Gaza:** Hamas security chief killed in Israeli airstrike. At least 6 killed.
- **Ukraine:** Zaporizhzhia apartment building hit, 2 killed. Russia says 699 drones downed overnight.
- **Hanoi:** Suspected gas explosion at a hot pot restaurant, 6 killed.
- **Landmines:** 6,929 casualties in 2025, a five-year high. Civilians 84%.
- **UK sanctions:** UK sanctions the Houthis and 4 officials.
- **Seoul:** South Korea scrambles jets after Russian aircraft enter its air defense zone.

Every number in the image was verified against reporting on the day; no unverified figure is used. The Zaporizhzhia wounded count is left out because sources disagree on it.

## How it works

Run `python3 main.py` — it copies `news.png` (1024×1024) to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere. The program is deterministic: no network, no randomness, no timestamps, so two runs write byte-identical files.
